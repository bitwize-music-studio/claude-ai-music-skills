## Suno images and video

Nothing in your content, audio or documents folders changes. New output goes beside the album's audio: `lyric_videos/`, `music_videos/`, and `promo_videos/<track>_suno.mp4`.

### What changed for me as a user?

- **Album art through Suno.** Set `artwork.generator: suno` to have Suno's image tool make the cover. `manual` (the default) and `codex` work as before. Measured with the Fast model (`image-1`): two 1024x1024 images for 1 Visuals credit.
- **Lyric videos, promo clips and music videos.** Use these only when you ask for them. Each one prices its request with a dry run, states the cost and waits for a yes.
- **Permission prompts for Suno tools a skill doesn't use.** Before, eleven skills could call any Suno tool without asking, including the new paid image and video tools. Now each skill lists the tools it calls.

## Dependency updates

This release moves the pinned versions in `requirements.txt`. The venv at `~/.bitwize-music/venv` only changes when you run the fix command, so until then the MCP server keeps running on the old packages.

- **playwright 1.65.0 → 1.65.2.** Chromium 159 instead of 158, and a Node.js security release in the driver. Until you run the manual step above, document-hunter fails at browser launch with Playwright's "Executable doesn't exist" error.
- **pypdf 7.0.1 → 7.1.0.** Performance work and two deprecations the plugin doesn't touch.
- **boto3** moves to 1.44.3, AWS API-model updates only.
