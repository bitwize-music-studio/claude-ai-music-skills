## Dependency updates

Nothing in your content, audio or documents folders changes. This release moves the pinned versions in `requirements.txt`. The venv at `~/.bitwize-music/venv` only changes when you run the fix command, so until then the MCP server keeps running on the old packages.

### What changed for me as a user?

- **pypdf 7.0.0 → 7.0.1.** Bug fixes, among them the page lookup in hierarchical page trees when writing a PDF, which `create_songbook` and `prepare_singles` do, plus one security hardening item. No advisory is published against 7.0.0.
- **playwright 1.64.1 → 1.65.0.** Chromium 158 instead of 156. Until you run the manual step above, document-hunter fails at browser launch with Playwright's "Executable doesn't exist" error.
- **boto3** moves to 1.44.0, AWS API-model updates only.
